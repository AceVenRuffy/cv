# Lebenslauf / Resume | Edgar Heinz

Statische CV-Seite (DE/EN), live auf https://cv.edgarheinz.com

- Inhalte & Design werden von `build.py` generiert → schreibt nach `docs/` (GitHub Pages).
- Gestaltung wie edgarheinz.com (Projekt `~/Projects/Portfolio`): helles Grau, Lichtstreifen, weiße Pills,
  Akzent Orange, dunkle Fläche am Ende. Hell ist Standard, dunkel per Umschalter, gedruckt wird immer hell.
- Ändern: Texte in `build.py` anpassen, `python3 build.py --pdf` ausführen, committen & pushen.
- PDF: Der Button lädt die fertige Datei aus `docs/`. `--pdf` erzeugt beide PDFs neu aus der Druckansicht
  (Headless-Chrome, A4, zwei Seiten). Nach Textänderungen prüfen, ob es bei zwei Seiten bleibt.
- Texte ohne Gedankenstriche, Bereiche heißen wie auf der Website (Webdesign, Werbung, Eventdesign).
